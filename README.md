# שישה סקילים לסטודנטים - מתחילים כאן

הערכה כוללת שישה Skills ל-Claude, מדריך התקנה, משפטי פתיחה וקובצי דוגמה. כל הדוגמאות פיקטיביות. הסקילים אינם מותקנים בחשבון שלכם אוטומטית.

## התקנה ב-Claude - 3 צעדים

1. [הורידו את הערכה המלאה](https://github.com/Adidinahon/student-claude-skills/releases/download/v1.0.0/student-skills-pack.zip) וחלצו אותה.
2. היכנסו ל-[Customize > Skills](https://claude.ai/customize/skills). לחצו על `+`, בחרו `Create skill` ואז `Upload a skill`.
3. העלו בנפרד את ששת קובצי ה-ZIP שבתיקייה `install/`. פתחו שיחה חדשה ונסו משפט מתוך `EXAMPLE-PROMPTS.md` עם קובץ מהתיקייה `examples/`.

אם כפתור ה-Skills חסר, ראו [פתרון תקלות קצר](INSTALL.md). למשתמשי Claude Code יש שם גם הוראת התקנה נפרדת.

## מה מקבלים

| סקיל | תוצאה |
| --- | --- |
| `lecture-organizer` | מארגן הרצאות והערות למפת למידה |
| `paper-decoder` | מפרק מאמר לשאלה, שיטה, ממצאים ומגבלות |
| `socratic-tutor` | מלמד בשאלות וברמזים מדורגים |
| `practice-exam` | בוחן מתוך חומרי הקורס ונותן משוב |
| `exam-plan` | בונה תוכנית למבחן לפי תאריך וזמן פנוי |
| `draft-feedback` | נותן משוב על טיוטה מול מחוון |

הסקילים העריכים נמצאים ב-`skills/`. קובצי ההתקנה ל-Claude נמצאים ב-`install/`. הוראות מלאות ב-`INSTALL.md`, בקשות מוכנות ב-`EXAMPLE-PROMPTS.md`, קלט פיקטיבי ב-`examples/`, ופלטי הדגמה ב-`DEMO-OUTPUTS.md` וב-`demo-results/`.

## לפני השימוש

העלו רק חומר שמותר לשתף עם שירות חיצוני. בדקו מקורות, ציטוטים, חישובים ותאריכים מול החומר המקורי, ופעלו לפי כללי המוסד לגבי שימוש ב-AI במטלות. הסקילים עוזרים ללמוד ולשפר טיוטה, ולא מבטיחים ציון או מחליפים עבודה עצמאית.
